# 30 שנה: המבחן

אתר אינטראקטיבי לערב חגיגת 30 שנות נישואים לחיים ועינת · 31.8
קובץ HTML יחיד, עובד לגמרי אופליין, בנוי לאייפד במצב לנדסקייפ.

## איך מפעילים
פותחים את `index.html` בספארי באייפד. זהו.
אפשר גם להעלות את התיקייה כמו שהיא ל-GitHub Pages.

## שלושה דברים לעשות לפני הערב

**1. להוריד את הפונטים (פעם אחת, עם אינטרנט):**

```bash
bash fetch-fonts.sh
```

הקבצים נשמרים ב-`fonts/` והאתר כבר לא צריך רשת לעולם.
אם מדלגים על זה — האתר עובד, פשוט עם הפונטים של המערכת.

**2. תמונות** — 26 תמונות כבר בפנים (7 אמיתיות ו-19 שנוצרו ב-AI).
חסרות עוד שלוש: `young-couple.jpg`, `wedding-crowd.jpg`, `rocky.jpg`.
הרשימה המלאה עם השמות המדויקים ומיקום כל תמונה נמצאת ב-`assets/README.txt`.
תמונה שחסרה לא שוברת כלום, פשוט מופיע מלבן עם שם הקובץ.

**3. למלא את התשובות מהראיונות המוקדמים.**
פותחים את `index.html` בעורך טקסט, גוללים למערך `QUESTIONS` בתחילת הקובץ,
ומחליפים כל מקום שכתוב בו `[למלא]`. אין צורך לגעת בשום קוד — כל התוכן יושב שם,
מופרד לחלוטין מהלוגיקה, עם הסבר על כל שדה מעל המערך.

## איך מנחים את הערב

- כפתור מג'נטה ענק למטה = השלב הבא. זה כל מה שצריך.
- **קדימה ←** / **→ אחורה** בפינות התחתונות, או החלקה על המסך.
- הנקודות למעלה = קפיצה ישירה לכל שאלה.
- מקלדת (לחזרות בבית): רווח או חץ שמאלה = הבא, חץ ימינה = אחורה, `R` = חשיפה.
- **שאלה 6 נעולה:** מקלידים את שני הניחושים בתחילת הערב, לוחצים "לנעול עד הקינוח",
  ופותחים רק כשמגיעה העוגה.
- **הצבעות:** כל סבב מוגבל למספר האנשים שנמצאים בערב. מד הנקודות מתחת לשאלה
  מראה כמה קולות נשארו, וכשכולם הצביעו הכפתורים ננעלים לבד.
  הרשימה נמצאת במשתנה `VOTERS` בראש הקובץ — מי שלא הגיע, מוחקים משם והמגבלה מתעדכנת.
  יש "לבטל קול אחרון" ו"לאפס את הסבב", ואפשר גם לפתוח מחדש הצבעה שנסגרה.
  אין מצב שאי אפשר לצאת ממנו.
- הכל נשמר אוטומטית. אם האייפד ננעל או הדף נטען מחדש — חוזרים בדיוק לאותו מקום,
  עם ההצבעות והטקסטים.
